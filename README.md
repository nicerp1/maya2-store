# مایا آزما — مایا2

فروشگاه فارسی و RTL تجهیزات آزمایشگاهی با رابط Vanilla JavaScript، API مبتنی بر Express، Prisma و PostgreSQL.

## قابلیت‌ها

- صفحه اصلی، دسته‌بندی، برند، پیشنهاد ویژه و جستجو
- فهرست محصولات با فیلتر و مرتب‌سازی
- جزئیات محصول، تنوع، مشخصات و دیدگاه‌ها
- سبد خرید، علاقه‌مندی و کد تخفیف `MAYA10`
- ثبت‌نام/ورود، حساب کاربری و سفارش‌ها
- تسویه‌حساب، کارت بانکی نمایشی و پرداخت Mock
- ثبت و پیگیری سفارش با تایم‌لاین
- داشبورد RTL مدیریت و جدول محصولات
- طراحی واکنش‌گرا و حالت تاریک پایدار
- مدل کامل PostgreSQL و APIهای محافظت‌شده با JWT
- Helmet، CORS، Rate Limit، bcrypt و کنترل نقش مدیر

## اجرای فوری رابط

این روش به پکیج خارجی نیاز ندارد:

```bash
node static-server.mjs
```

سپس `http://127.0.0.1:3000` را باز کنید. اطلاعات نسخه فوری در `localStorage` مرورگر نگهداری می‌شود.

## اجرای کامل با PostgreSQL

پیش‌نیازها: Node.js 20+ و Docker Desktop یا PostgreSQL 15+.

```bash
copy .env.example backend\.env
npm install
npm --prefix backend install
docker compose up -d
npm run prisma:migrate -- --name init
npm run prisma:seed
npm run dev
```

Frontend روی `http://localhost:3000` و API روی `http://localhost:4000` اجرا می‌شود. مقدار `JWT_SECRET` را پیش از اجرا تغییر دهید.

## حساب‌های آزمایشی

حساب‌ها و رمزهای توسعه‌ای در مخزن عمومی نگهداری نمی‌شوند. پیش از استفادهٔ واقعی، حساب مدیر و رمز امن را از طریق تنظیمات محیطی ایجاد کنید.

## تست و API

```bash
node --test backend/test/smoke.test.js
npm run lint
```

درخواست‌های آماده در `tests/api.http` و مستندات مسیرها در `docs/API.md` قرار دارند.

## نکات تولید

- پرداخت فعلی Mock است و هیچ اطلاعات کارت بانکی ارسال یا ذخیره نمی‌شود.
- برای تولید باید درگاه ایرانی، ایمیل بازیابی رمز، ذخیره‌سازی امن تصاویر، HTTPS، Secure Cookie و مانیتورینگ اضافه و تنظیم شوند.
- Backend قیمت، موجودی، تخفیف و جمع سفارش را مجدداً محاسبه می‌کند و به مقدارهای رابط اعتماد نمی‌کند.
